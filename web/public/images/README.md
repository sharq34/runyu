# 照片文件名对照

把照片放到这个目录，文件名按下表。没放的照片页面上会显示占位块，不影响运行。
建议先压到长边 1600px 左右（首页背景可以 2000px），手机看足够，也省流量。

## 换照片 / 加照片

在 `web/src/photos.ts` 的 PHOTOS 数组里改。每一项：

- `file`：文件名
- `caption`：一句话标题（常驻）
- `story`：背后的故事（悬停 / 点开显示）
- `ratio`：原图宽 / 高，竖屏 3:4 写 `3 / 4`，2:3 写 `2 / 3`，横屏 4:3 写 `4 / 3`
- `wide: true`：横屏照片加这个，网格里横跨两格，手机上占满一行
- `focus`：裁切时优先保留哪里，比如 `'50% 70%'` 保留偏下的部分

竖屏和横屏可以混放。为了网格排满，横屏算 2 格、竖屏算 1 格，
电脑上每行 4 格、手机上每行 2 格，总格数尽量是 4 的倍数。
